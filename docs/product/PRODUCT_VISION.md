# Product Vision: NovaSphere AI / OmniAgent Social Media Platform

## 1. Executive Summary
NovaSphere AI is a streamlined, unified, and secure Social Media Management Platform designed specifically to replace complex, bloated enterprise AI workflows with everyday publishing power. It allows individual creators, influencers, media agencies, and business brands to compose, preview, schedule, and publish multimedia content across Instagram, Telegram, and YouTube from a single web interface.

## 2. Core Philosophy: Radical Simplicity Over Enterprise Bloat
1. **User-Centric Workflows:** Non-technical users can connect their accounts in under 2 minutes and publish a post across multiple networks in 3 clicks.
2. **Strict 8-Item Navigation:**
   - **Dashboard (`/dashboard`):** Real-time status, upcoming queue, recent post delivery history, account health.
   - **Create Post (`/create-post`):** Single-screen workflow with multi-network selector, live platform previews, media uploader, and AI caption assistant.
   - **Calendar (`/calendar`):** Monthly and weekly interactive scheduling matrix.
   - **Connected Accounts (`/accounts`):** Official OAuth & Bot API account manager protected by AES-256 Token Vault.
   - **Media Library (`/media`):** Drag-and-drop asset storage for images and videos.
   - **Published Posts (`/published`):** Live delivery log with platform post IDs, live links, error diagnostics, and 1-click retry.
   - **Analytics (`/analytics`):** Real-time audience reach and engagement tracking.
   - **Settings (`/settings`):** Workspace members, API configurations, and localization preferences.

## 3. Platform Tiers & Capabilities
- **Tier 1 (Core & Active):**
  - **Instagram:** Feed images, Reels, Carousels via Meta Graph API Container workflow.
  - **Telegram:** Bot API broadcasting to channels and discussion groups with Markdown/HTML formatting.
  - **YouTube:** Resumable video uploads via YouTube Data API v3 with title, description, tags, and privacy settings.
- **Tier 2 (Gated by External Approval):**
  - **TikTok:** Marked `BLOCKED_BY_EXTERNAL_APPROVAL` pending commercial app audit.
  - **LinkedIn:** Marked `BLOCKED_BY_EXTERNAL_APPROVAL` pending company partner approval.
